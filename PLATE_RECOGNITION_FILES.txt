API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

GET /health
  Purpose: Service status check
  Returns: {status, service, api_configured, timestamp}

POST /api/detect-plate
  Purpose: Detect plates in image
  Accepts: Binary image data
  Returns: {success, results, processing_time, dimensions, timestamp}

POST /api/detect-plate-base64
  Purpose: Detect plates in base64 image
  Accepts: {image: "base64-string"}
  Returns: Same as binary endpoint

TROUBLESHOOTING QUICK REFERENCE
═════════════════════════════════════════════════════════════════════════════

Port 5001 in use?
  $ kill -9 $(lsof -t -i:5001)

Flask won't start?
  Check Python version (3.7+)
  Check dependencies installed
  Check for syntax errors

Can't connect to Flask?
  Check .env has VITE_PLATE_API_URL=http://localhost:5001
  Check Flask service running
  Check port 5001 is open

No plates detected?
  Try different car image
  Ensure plate is clearly visible
  Check image quality
  This is normal if no plates in image

API token errors?
  Get token from https://platerecognizer.com/
  Update VITE_PLATE_API_TOKEN in .env
  Service works in demo mode without token
